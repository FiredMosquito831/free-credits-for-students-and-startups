data.gov.uk: free credits and offers

Best offer on record: ODI / data.gov.uk directory API (CKAN) — free, no key, no account. 5 verified findings, checked 2026-10-22.

Offers

ODI / data.gov.uk directory API (CKAN) — free, no key, no account high confidence

The legacy ODI (Open Data Inventory, CKAN) directory API is still live and free for everyone, including students and startups. Verified 2026-10-22: GET https://data.gov.uk/api/3/action/... 301-redirects to https://ckan.publishing.service.gov.uk/api/3/action/... and package_search returns success with count = 59,462 datasets (the '30,000+' figure is stale). Standard CKAN actions available (package_search, organization_list, resource_show, datastore endpoints on some datasets). No API key, no registration, no credit card, no rate-limit headers or quota fields returned. All datasets are licensed under the Open Government Licence (OGL); platform content under OGL v3.0.

Eligibility
Unconditional — open to anyone, no .edu email, no age/funding criteria, no region limits. Free, indefinite, renewable by nature (public service, no expiry).
How to claim
No claiming required. Just call the REST endpoints, e.g. https://data.gov.uk/api/3/action/package_search?rows=10 (or via ckan.publishing.service.gov.uk). For programmatic bulk metadata, use the CKAN dumps (see separate finding). Dataset publishers are public-sector orgs; for a specific dataset, contact the publisher if you need something not published.
Expiry
No expiry. In the March 2026 rebrand the directory was kept 'unchanged for now'; the June 2026 roadmap lists 'critical improvements to the original directory' as ongoing work, with no deprecation date announced.
Gotchas
The CKAN dataset page's API links/docs are dated 2014 and the old /terms-and-conditions page now 404s, so rate limits are undocumented — be gentle on traffic. ~25% of dataset resource links are broken and many datasets are stale; the API metadata is not a guarantee the underlying data file exists. 'ODI' here means the Open Data Inventory (a GDS-operated portal), not the Open Data Institute nonprofit.

Open data downloads via the data.gov.uk directory (Search & CMS front) — free, OGL-licensed high confidence

Every dataset on the original open data directory (the 'data.gov.uk directory', still searchable alongside the new National Data Library curated collections) is free to download in its native format (CSV, JSON, S3 pointers, API feeds). Free, unlimited use with attribution under the Open Government Licence; no account, trial, or tier of any kind — there is simply no pricing model on data.gov.uk. Students and startups get the identical offer as everyone else.

Eligibility
Open to anyone worldwide; no .edu requirement, no startup age/funding cap, no credit card. OGL v3.0 applies to site content; individual datasets state their licence (OGL, ODbL, CC, or publisher-specific).
How to claim
Search the directory (link on https://www.data.gov.uk/) or use the CKAN API, pick a dataset, download the data files. For data not available in bulk, the support page directs users to contact the dataset publisher directly; data.gov.uk itself cannot host data or combine datasets.
Expiry
Indefinite; subject to each publisher's lifecycle. No sunset date announced for the directory.
Gotchas
Data quality is the main gotcha, not access cost: the service has been underinvested since ~2017, with many broken/outdated links (per GDS's own March 2026 blog). Some datasets are CC-licensed with restrictions (e.g. no commercial use without attribution) — check the licence field per dataset before building a startup on it.
Source
dataingovernment.blog.gov.uk

Bulk CKAN metadata dumps (free, nightly, S3) medium confidence

GDS publishes a zipped CSV or JSONL dump of the metadata for all data.gov.uk datasets nightly, and hosts historical dumps in a public S3 bucket (dgu-ckan-metadata-dumps.s3-eu-west-1.amazonaws.com, us-east/eu-west). The .jsonl 'v2' dump (ckanapi dump output, includes full organization details, QA/broken-link flags, format detection) supersedes the old JSON dump. Free to fetch; no key. Uncompressed files can be ~170 MB+ — build pipelines rather than loading into spreadsheets, per the publisher's own note.

Eligibility
Unconditional, free, no account or CC.
How to claim
Grab the dump URL from the dataset page (https://www.data.gov.uk/dataset/b5e4be7e-6c36-41b6-9d48-cae195c32e34/meta-data-for-data-gov-uk-datasets) or the S3 bucket directly (list objects, no credentials needed for a public bucket).
Expiry
Published nightly; no announced end date.
Gotchas
Dumps are metadata only (links + descriptions), not the datasets themselves; old .json dump was discontinued after a 3-month transition in 2016 — use .v2.jsonl. The 2015 CSV column change (datasets vs resources in separate files) is still in effect; join on the 'Name' column.

data.gov.uk

National Data Library (data.gov.uk rebrand) + GDS API Hub (alpha) — free, early-stage, no products to buy yet high confidence

As of March 25, 2026 data.gov.uk launched as the 'National Data Library' (NDL): curated data collections (Business & economy, Environment, Government, Land & property, People, Transport, Early years) plus a 'data manual', backed by >£100M within DSIT's £1.9B spending-review allocation. Separately, GDS's API Hub was in a 12-week alpha (results blogged 28 Nov 2025) with a planned MVP of a free central API catalogue (with quality/security scores and a signed-in developer portal) aligned with data.gov.uk and datamarketplace.gov.uk. All of it is free-open-access; there is no paid tier, trial credit, startup program, or education license anywhere in the NDL or the old directory.

Eligibility
Open access, no sign-in required for browsing/collections; the API Hub's 'signed-in developer portal' is only a future exploration. No .edu or startup criteria because no gated offer exists.
How to claim
Nothing to claim — browse https://www.data.gov.uk/ collections and the roadmap; give feedback via the forms to influence direction. GDS is actively soliciting developer input on the API Hub (blog feedback form).
Expiry
Roadmap updated at least every 6 months (next review after the June 2026 version); 'details on the National Data Library in spring 2026' per the January 2026 progress update — i.e. new access mechanisms may ship in 2026. The API Hub has no committed date.
Gotchas
Do not build on the API Hub — it is an alpha research program, not a product. The NDL currently exposes only non-personal, aggregated data; personal-data linkage (kickstarter projects) is exploratory. The 'National Data Hub' open data API from the task's known-so-far note is not a thing: the term does not appear in any official 2026 document — the program is the National Data Library.
Source
gov.uk

No student-specific, startup-specific, or education-licensed offers exist on data.gov.uk high confidence

data.gov.uk (ODI CKAN API, directory downloads, NDL collections) has no pricing at all: no free-tier vs paid-tier distinction, no trial credits, no startup program, no .edu-gated education license, no credit-card-on-file free plans. The entire offer is unconditionally free OGL-licensed public data with no registration. For students and startups the 'free offer' is therefore simply universal free access — identical to everyone else's — with the caveats in the findings above (broken links, per-dataset licence variants, undocumented rate limits).

Eligibility
N/A — universal, unconditional.
How to claim
N/A — nothing to claim; just use the API/download links directly.
Expiry
Indefinite public service; no offer to renew.
Gotchas
Watch for NDL milestones: the January 2026 progress update promises more detail in spring 2026, and kickstarter projects (legal data for SMEs, Met Office weather, social care) could spawn new access services; the GDS API Hub MVP may eventually add an authenticated developer portal. Also note the 2025-2026 external sunsets listed in sunset_notes.

2025–26 changes

  • 2025-2026 changes: (1) data.gov.uk was redesigned/rebranded as the National Data Library, published 25 March 2026 (new landing page, curated collections, data manual, public roadmap at /roadmap/, June 2026 version); the original ODI CKAN directory survives as the 'data.gov.uk directory', unchanged for now, with GDS fixing 'critical issues'. (2) The 'National Data Hub' named in the task's known-so-far is a misnomer — no such API product appears in official documents; the program is the National Data Library (>£100M of DSIT's £1.9B; progress update 26 Jan 2026; spring-2026 detail milestone). (3) Related UK open-data sunsets: ONS PublishMyData API fully decommissioned 31 March 2025 (outage from 3 March 2025; data moved to ONS portals and the new ONS Data API / api.beta.ons.gov.uk/v1/search), and ONS retired its aggregated-search /data endpoints in favour of the ONS Search API. (4) The old ODI terms-and-conditions URL (data.gov.uk/terms-and-conditions) now 404s, so documented rate limits are gone — access remains free and keyless. (5) No free-tier, trial-credit, startup-program, or education-license offer existed or changed on data.gov.uk in 2025-2026: it was and is unconditionally free under the Open Government Licence, so there is nothing student/startup-specific to sunset.
