Data.gov: free credits and offers

Best offer on record: Data.gov open data catalog — free, no key, no card, no account. 5 verified findings, checked 2026-10-22.

Offers

Data.gov open data catalog — free, no key, no card, no account high confidence

catalog.data.gov holds 431,094+ datasets from US federal agencies, with direct file downloads (CSV, JSON, XML, XLSX, ZIP) and full search/filter (by organization, geospatial extent, popularity, recency, 'only show datasets with a downloadable file'). No registration, sign-in, API key, or credit card is required to search or download. US federal government works are generally in the public domain, so no special education or commercial license is needed. Counts and dataset counts are live on data.gov/metrics. Gotcha: data.gov does not host the underlying data — it's a metadata catalog that harvests agency pages; broken download links and data-quality issues are the agencies' responsibility (contact DataGovHelp@gsa.gov or the owning agency).

Eligibility
Universal: any student, startup, or organization anywhere in the world. No .edu email, no startup age/funding cap, no credit card, no region limit.
How to claim
Go to catalog.data.gov, search or filter datasets, and click the download links on the dataset page (filter: 'Only show datasets with a downloadable file'). No signup at all.
Expiry
Indefinite — maintained under the OPEN Government Data Act; no trial period, no expiry, no renewal.
Gotchas
No data hosting/quality guarantees; link rot possible; individual agencies may impose their own download constraints on their source pages; attribution to the owning agency is courtesy, not law.
Source
catalog.data.gov

Data.gov catalog API v4 (api.gsa.gov/technology/datagov/v4) — free API key, 1,000 req/hour high confidence

The current catalog API is a public REST/JSON API at https://api.gsa.gov/technology/datagov/v4/ with endpoints: /search (q, sort, per_page default 10, org_slug, keyword, spatial_filter/spatial_geometry/spatial_within, after-cursor pagination), /api/keywords (size up to 1000), /api/locations/search, /api/location/{id}, /api/organizations, /harvest_record/{id} (+ /raw and /transformed). A key is REQUIRED (X-Api-Key header, api_key query param, or Basic auth with key as username), but keys are free via api.data.gov: a 40-character personal key with 1,000 requests/hour and no daily cap, valid across all api.data.gov services. No credit card required, no key expiry stated; overuse returns HTTP 429 with a temporary 1-hour block; admins can disable keys. Responses include X-RateLimit-Limit/Remaining headers. Errors: 403 API_KEY_MISSING/INVALID/UNVERIFIED, 422 bad params, 404 missing resource.

Eligibility
Universal: anyone (student/startup/company) can request a free key. No .edu email, no funding cap, no credit card, no region limit.
How to claim
Sign up free at api.data.gov to receive a 40-char personal API key (covers all 450+ participating agency APIs too), then call https://api.gsa.gov/technology/datagov/v4/search with the X-Api-Key header. 1,000 requests/hour, no daily cap.
Expiry
No stated expiry/renewal. Rate limit is 1,000 req/hour, no daily cap; 429 blocks last one hour. Keys can be disabled by administrators.
Gotchas
Key is mandatory here (unlike direct downloads); DCAT-US v3.0 migration means the access_level filter (public / restricted public / non-public) has only 'strong but not guaranteed' coverage; this v4 API replaced the CKAN-based catalog API (see sunset_notes).
Source
resources.data.gov

api.data.gov DEMO_KEY — no-signup trial access to the catalog API high confidence

The catalog API documentation provides a DEMO_KEY for 'initially exploring APIs prior to signing up'. Limits: 30 requests per IP address per hour AND 50 requests per IP address per day. The docs explicitly state it 'is not suitable for production use or automated queries'. This is the only true zero-account offer on the API front; upgrading to a personal key (free, no CC) removes both caps to 1,000/hour.

Eligibility
Universal, anonymous — no account, no .edu, no credit card, no region limit. IP-based limits, so shared/CGNAT IPs consume the 50/day pool together.
How to claim
Use the published DEMO_KEY value with the same X-Api-Key header against https://api.gsa.gov/technology/datagov/v4/ endpoints for up to 30 req/hour and 50 req/day per IP. For more, request a free personal key at api.data.gov.
Expiry
No expiry stated; per-IP windows (hourly/daily). Intended for exploration only.
Gotchas
Strictly trial-grade: 50 requests/day per IP; shared IPs compound the limit; docs prohibit production/automated use; hitting 429 waits an hour.
Source
resources.data.gov

api.data.gov free service key — one key across 450+ federal agency APIs (25 agencies) medium confidence

api.data.gov is GSA/Technology Transformation Services' 'free API management service for federal agencies' (built on NREL's open-source API Umbrella). A single free personal key 'gives you access to all APIs from agencies participating in api.data.gov's service' — 25 agencies and 450+ APIs including USGS, NASA, and FDA services. Keys are 40-character, free, with per-user rate limits (the catalog API slot is 1,000/hour; other participating APIs define their own limits per agency). Three ways to pass the key: X-Api-Key header, api_key query parameter (works with POST/PUT), or Basic auth (key as username, empty password). Usage analytics/dashboards are provided to keyholders; no credit card or account type restrictions were stated anywhere on the service pages.

Eligibility
Universal: students, startups, and any organization. No .edu email, no startup age/funding cap, no credit card, no region limit; US government service open to all.
How to claim
Register free at api.data.gov (key issuance described as 'quick and easy'), then call any participating agency API (e.g. the v4 Data.gov catalog API) with your key in the X-Api-Key header.
Expiry
No key expiry stated; keys can be administratively disabled (API_KEY_DISABLED); 429 rate-limit blocks lift after one hour; per-user limits can be raised or lowered per user.
Gotchas
The service itself is free but some underlying agency datasets/APIs may carry their own usage terms (docs say 'contact the API owner at the agency that offers the service'); per-API limits vary by agency; key issuance is unverified so expect a manual step (GSA form/email) — verify on the signup page.
Source
api.data.gov

Education license / startup program: none exist (by design) high confidence

Data.gov has no student tier, .edu discount, educational license, trial credits, or startup program, and no paid tier at all: it is a free, publicly funded GSA portal, so there is nothing to license. Every offer above is the same free program available to all users identically. Anyone citing a 'Data.gov student plan' is describing something that does not exist.

Eligibility
Not applicable — no eligibility screen anywhere; same free access for students, startups, researchers, and commercial users.
How to claim
Nothing to claim: use the free catalog downloads or the free api.data.gov key like anyone else. For classroom use, point students at catalog.data.gov (no account) or a shared DEMO_KEY/educational api.data.gov key.
Expiry
Not applicable.
Gotchas
Do not confuse with agency products that do have programs (e.g., Google for Education, AWS Credit for Research); no startup program replaces the universally free baseline.
Source
data.gov

2025–26 changes

  • Changes verified 2025-2026 (read from official pages today; WebSearch budget was exhausted, so this reflects the official pages rather than news searches): (1) The catalog API was rebuilt: the new v4 API at api.gsa.gov/technology/datagov/v4 (keyed via api.data.gov) 'replaces the previous CKAN-based API' per resources.data.gov/catalog-api; the docs claim the older CKAN endpoint 'remains available in a read-only state for existing integrations', but probes to catalog.data.gov's former CKAN paths (/api/3/action/..., /api/3/, /api/2/, /dataset.json) all returned HTTP 404 today, so that read-only availability is uncertain or on a different host — low confidence, verify before relying on legacy CKAN integrations. (2) The legacy standalone Data.gov 'Developer Program' key portal keys.data.gov no longer resolves (DNS ENOTFOUND today), i.e. that older free-API-key program (zip codes, geographic names, transit routes style lookups) has been retired; equivalent agency APIs now live under api.data.gov. (3) No price changes: everything remains free; the OPEN Government Data Act remains the statutory basis. Caveat: the known-context line 'many datasets need no key' is confirmed for downloads/search, but API access to the v4 catalog API does require a (free) key; agency-specific egress/download costs never apply to data.gov itself.
