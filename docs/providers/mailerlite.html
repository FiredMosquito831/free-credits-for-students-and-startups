MailerLite: free credits and offers

Best offer on record: Free Plan (standing, no credit card required). 6 verified findings, checked 2026-10-22.

Offers

Free Plan (standing, no credit card required) high confidence

Per official pricing page (fetched 2026-10-22): $0/mo, up to 250 active subscribers, 2,500 emails/month, 3 active automations (5 steps each), 3 active forms, 2 user seats, 1 website + 1 landing page, 1 digital product/booking, all 3 email editors, 100+ integrations, MCP for Claude/ChatGPT, knowledge-base support only. Explicitly 'No credit card required'. API/MCP/Webhooks are 'Limited' on Free (no API sending). No stated time limit — standing tier.

Eligibility
Anyone worldwide; no credit card required; no .edu or org proof. Region limits not documented on the page.
How to claim
1) Go to mailerlite.com and sign up (email-based, no CC). 2) Account lands on Free plan automatically. 3) Import/capture up to 250 subscribers via forms; send up to 2,500 email campaigns/automations per month.
Expiry
None — Free plan is a permanent tier, no expiry date documented.
Gotchas
Do not use the legacy numbers '1,000 subscribers / up to 12,000 emails/mo' — superseded; current Free is 250/2,500. MailerLite logo remains on email; no report exports, no custom domain permissions, KB-only support. Automation cap is 3 active x 5 steps. API/MCP access is limited on Free and excludes sending.
Source
mailerlite.com

14-day Premium trial (no credit card required) high confidence

Every new MailerLite account gets 14 days to try premium features (Comfort/Power-level features: 50 automations, more forms/sites, paid-plan features). No credit card required. When the trial ends, premium features lock but 'none of your data including subscribers, automations, forms, sites will be removed'. Paid plans start at $12/mo (Comfort, $25/mo Power; annual billing saves 10%).

Eligibility
All new accounts; no CC required; no documented region or org limits.
How to claim
1) Sign up for a new account — trial applies automatically, nothing to request. 2) Use premium features for 14 days. 3) If not upgrading, account reverts to Free plan limits.
Expiry
14 days from account creation; then premium features unavailable unless upgraded.
Gotchas
This is a trial, not a free tier — after 14 days you drop to Free (250 subs / 2,500 emails/mo) or must pay. Data is retained, not deleted. No CC required at start; upgrade later can add billing.
Source
mailerlite.com

API front: Limited on Free, sending paid-only; no free API credits; no SMS/Push/Chat product high confidence

Pricing FAQ: 'Email sending via the API and MCP server is available on paid plans' and 'On Free, API and MCP access is limited and doesn't include sending'. Free users can still make API/MCP/webhook requests (e.g., manage subscribers) within limits. Paid plans from $12/mo. MailerLite's only messaging front is email — no SMS, push, or chat product/API exists, so 'SMS, Push & Chat APIs' fronts have no offer here. API docs at developer.mailerlite.com sit behind login. No free tier of API sending credits exists.

Eligibility
API key available on all plans; API sending requires a paid plan (Comfort $12/mo+). No CC required for Free (read/manage only).
How to claim
1) Create an API key in the account (see help article 'MailerLite API key, Group ID, and documentation'). 2) Free plan: read/manage endpoints only. 3) To send email via API/MCP: upgrade to paid.
Expiry
n/a — follows plan; no credit expiry since no free send credits exist.
Gotchas
Do not assume the 2,500 free email sends can be dispatched via API — sending via API/MCP is paid-only. 'Limited' is not quantified on the public page (rate limits live in login-gated docs).
Source
mailerlite.com

Annual billing saves 10%. 'We can only apply one discount at a time.' Neither is a free offer and neither targets students or startups.
