GPUStack: free credits and offers

Best offer on record: Free open-source self-hosted runtime (the only real free offer; available to students and startups alike). 2 verified findings, checked 2026-10-22.

Offers

Free open-source self-hosted runtime (the only real free offer; available to students and startups alike) high confidence

GPUStack core is free, open-source, Apache 2.0 licensed (NOT MIT as the task's 'known so far' said — both gpustack.ai and the GitHub repo state Apache 2.0 today). One-line Docker install (server: sudo docker run -d --name gpustack -p 80:80 --volume gpustack-data:/var/lib/gpustack gpustack/gpustack; worker: separate privileged Docker command with --server-url and a generated --token). Includes Ollama-style local web UI + OpenAI/Anthropic-compatible API, model deployment, and supports heterogeneous accelerators (NVIDIA; AMD/ROCm, Ascend, Hygon, MetaX, Moore Threads, Cambricon, Iluvatar, T-Head PPU per the site). Free forever, no expiry. No hosted free tier, no trial credits, no student/education offer, no startup program exists on the official site (verified /, /enterprise, /blog, GitHub, docs quickstart on 2026-10-22; /cloud/ and /pricing/ are 404). Sources read today: https://gpustack.ai, https://gpustack.ai/enterprise, https://gpustack.ai/blog/, https://gpustack.ai/blog/introducing-gpustack/, https://github.com/gpustack/gpustack, https://docs.gpustack.ai/latest/quickstart/

Eligibility
Anyone — students, startups, enterprises, individuals. No .edu email, no account, no company age or funding-cap requirements, no region limits. Credit card NOT required; no commercial license, no login/account to set up (local 'admin' user with a system-generated password).
How to claim
Nothing to claim or sign up for: clone/download the open-source code (https://github.com/gpustack/gpustack) and run the Docker one-liners from https://docs.gpustack.ai/latest/quickstart/. Worker nodes need Linux + at least one GPU (docs quickstart covers NVIDIA; site advertises AMD/ROCm and Chinese accelerators too; macOS/Windows can host the server via Docker Desktop, workers are Linux-only; Windows via WSL2).
Expiry
Indefinite — Apache 2.0 license is perpetual; no sunsetting date for the open-source product.
Gotchas
The 'free compute' is BYO-hardware: you pay for your own GPU, electricity, and (for model pulls from hub sources) data egress; there is no GPUStack-hosted free GPU pool. Workers are Linux-only — no macOS worker nodes. RBAC, SSO (OIDC/SAML/LDAP), token quotas, metering & billing, white-label, HA and multi-tenancy are Enterprise features sold via 'Talk to Sales'/'Book a Demo' (https://gpustack.ai/book-demo) with no published pricing — do not assume free. The June 2026 'Introducing GPUStack' blog repositions the product as an 'enterprise AI infrastructure platform' with 'MaaS and GPUaaS under one control plane' (https://gpustack.ai/blog/introducing-gpustack/), so a commercial hosted GPUaaS is signaled, but no public self-serve page, pricing, or free tier for it was found (gpustack.ai/cloud and gpustack.ai/pricing return 404). WebSearch was unavailable this session (session budget exhausted), so third-party sources (funding news, off-site discount resellers) could not be checked.

GPUStack Enterprise (paid, sales-led — NOT a free offer; listed so it is not confused with a free tier) medium confidence

Enterprise adds high availability, multi-tenancy, RBAC/SSO, token quotas, rate limits, audit logs, metering & billing, white-label. No dollar figures, no tiers, no trial credits, no self-serve purchase anywhere on gpustack.ai; the only CTA is 'Talk to Sales' → /book-demo. A free trial or evaluation sandbox may be negotiated via sales but is not publicly published. Sources: https://gpustack.ai/enterprise, https://gpustack.ai/book-demo

Eligibility
Enterprise/sales channel; no public self-serve. No student or startup eligibility criteria published.
How to claim
Book a demo at https://gpustack.ai/book-demo/ to request evaluation or pricing; nothing claimable online.
Expiry
n/a (no published free component)
Gotchas
Verify what is actually free vs. Enterprise-locked before self-hosting in production; the metering/billing and white-label features are on the paid side of the line.
Source
gpustack.ai

2025–26 changes

  • No student, education, or startup program existed to sunset, and no trial-credit program was closed, in 2025-2026 — GPUStack has run exclusively as (a) a free Apache-2.0 self-hosted runtime and (b) a sales-led Enterprise product, with no published pricing pages (/pricing/ and /cloud/ are 404 as of 2026-10-22). Material 2025-2026 changes to note: (1) the task's 'known so far' claim of an MIT license is wrong — both the official site and the GitHub repo say Apache 2.0 today; (2) November 2025 'v2' and March 2026 'v2.1' releases added faster inference, Alibaba T-Head PPU support, a model gateway with routing, and a community backend marketplace (per https://gpustack.ai/blog/ listing; individual release details not fetched, so medium confidence on the specifics); (3) in June 2026 GPUStack repositioned as an 'enterprise AI infrastructure platform' marketing 'MaaS and GPUaaS under one control plane' (https://gpustack.ai/blog/introducing-gpustack/) — a hosted GPUaaS is signaled but had no public self-serve page, pricing, or free tier as of 2026-10-22. The original https://gpustack.co domain does not resolve; gpustack.ai is the live official domain. Caveat: the session's WebSearch budget was exhausted, so all 'no program exists' conclusions rest on official-page fetches done today only; an off-site program (e.g., a partner marketplace discount) could not be ruled out via search.
