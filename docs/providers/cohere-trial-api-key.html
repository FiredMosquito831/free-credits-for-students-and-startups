Cohere Trial API key: free credits and offers

Best offer on record: Cohere Trial API key (free tier, self-serve). 4 verified findings, checked 2026-10-22.

Offers

Cohere Trial API key (free tier, self-serve) high confidence

Auto-issued Trial API key on account creation: all API calls free, 1,000 API calls/month across all endpoints combined (per official docs.cohere.com rate-limits page; not stated on the pricing FAQ itself), with per-endpoint rate limits: Chat 20 req/min per model (Command A+, A Reasoning, A Translate, A Vision, Command A, R+, R, R7B, North Mini Code), Embed 2,000 inputs/min (same as production), Embed (Images) 5 inputs/min, Rerank 10 req/min, Tokenize 100 req/min, Parse 500 req/min, Audio Transcriptions 5 req/min. No credit card required; non-commercial use only — trial keys are explicitly 'not permitted to be used for production or commercial purposes'. No expiry date published; monthly quota resets on calendar month.

Eligibility
Anyone — any email, sign up at dashboard.cohere.com (email, Google, or GitHub). No .edu requirement, no student status, no region limit stated. No credit card or payment required.
How to claim
Sign up at dashboard.cohere.com; the Trial key is generated automatically and is copyable from the dashboard / 'API Keys' section. No application step. Usage caps: 1,000 calls/month total; 429s when rate limits or monthly cap hit; 402 when account billing limit reached.
Expiry
No published end date; 1,000-call monthly quota resets each calendar month. Key remains available for the life of the account.
Gotchas
Trial-vs-free: this is a permanent free tier, not a time-boxed trial, but strictly non-commercial — commercial production use requires a paid Production key (Owner completes 'Go to Production' workflow; pay-as-you-go, invoiced monthly or at $250 outstanding balance). 2026 change: for newer Chat model variants (Command A+, Command A Reasoning/Translate/Vision) production keys are capped like trial keys (1,000 calls/month, 20 req/min) and commercial use of those models requires contacting sales@cohere.com — so the free tier is the only self-serve access for the newest models. Data: Cohere logs prompts/generations, deleted after 30 days; opt out via Settings -> Data Controls. Third-party 'student deal' listings (e.g. The Modelverse) that tout '.edu verified, 365-day grant' are just rebrands of this same universal trial key — no .edu verification or separate grant exists.

Cohere Labs Catalyst Grants (research / education / public-benefit API credits) high confidence

Free Cohere API access (credits + compute) for academic partners, civic and public-impact organizations. Amounts per grant are not fixed or published; program page shows running totals (counters for grants awarded, $k in API credits, countries, university affiliations; third-party mid-2025 figure: 250+ grants, ~$350K API credits, 35+ countries). Credits tracked in the dashboard Billing tab; a Production API key is required to use them; if credits run out, contact brittawnya@cohere.com for more. AI-safety research has disclosure obligations: vulnerabilities must be disclosed unconditionally to labs@cohere.com at least 4 weeks before publication; no other pre-publication approval required.

Eligibility
Academic partners, civic and public-impact organizations (not strictly .edu-only — no formal .edu rule, but projects must be public-benefit or open-science research; non-commercial). Focus areas: education, healthcare, climate, sustainability, multilingual work, model safety, prosocial applications, values alignment. Credit card not required.
How to claim
Apply via the form at cohere.com/research/grants/application (official page cohere.com/research/grants). Rolling consideration, no fixed deadline. Colleagues outside your institution can be invited to use the credits via the dashboard Team tab. Optional acknowledgment line: 'This work was supported by compute credits from a Cohere Labs Research Grant.'
Expiry
No sunset published; application status shown as 'Open / rolling basis' as of today.
Gotchas
Credits are project/eligibility-scoped, not a universal student tier — individual students only get access via a faculty/institutional grant (or they apply as part of a qualifying organization). Grants are competitive and rolling, so timing is unpredictable. Grant access uses a Production key, meaning the non-commercial restriction of trial keys is replaced by the public-benefit/open-science restriction instead. The Sep 2025 education post is marketing for this same program, not a separate education license.
Source
cohere.com

Cohere Startup Program (2024 cohort) — 25% off for 12 months + partner-VC credits — CLOSED high confidence

Launched June 6, 2024: 25% discount on Cohere's proprietary models for one year, plus engineering support, logo/use-case showcase on cohere.com, joint webinars and co-marketing; zero equity; historically up to $100,000 API credits available to startups affiliated with partner VCs/accelerators. It was a discount program, not upfront free credits. Cohere's own post carried the note 'Applications are now closed for 2024' and no 2025/2026 cohort was announced.

Eligibility
At closure: early-stage AI startups from bootstrapped through Series B, building on Cohere tech, global (no published country restriction). The 25%-off benefit ran for 12 months from acceptance.
How to claim
No live claim path: cohere.com/startup-program and /startup-program-application now redirect to the cohere.com homepage (verified today, 2026-10-22, and re-verified by independent trackers on 2026-10-09 and 2026-10-10); cohere.com/startups returns 404. While it was open: submit the application, Cohere's team reviewed fit, then 25% discount applied at the billing layer for a year. Current substitute for prototyping: the free Trial key; for paid use: production keys or AWS Activate credits on Cohere models in Amazon Bedrock.
Expiry
Closed: 'Applications are now closed for 2024' per Cohere's post; program URLs dead as of 2026-10-09/10-22. No renewal announced.
Gotchas
Do not plan around this program: no closure notice was published, it simply lapsed — the launch post body is thin and the numbers above come from the post plus trackers. It is distinct from the Catalyst Grants (which cover research/public-benefit, not commercial startups). Third-party directories still list it as 'active' (e.g. SaaSTweaks, Startup Intros 'Cohere for Good') — ignore those; the official URLs are dead as of October 2026.

No dedicated student .edu license — education access rides on the universal trial key + Catalyst Grants medium confidence

As of 2026-10-22 there is no Cohere student/education license, no .edu-verified free tier, and no student credit card offer. Students get the same 1,000-calls/month trial key as everyone else (non-commercial, which covers coursework/personal projects but not a commercial product), plus eligibility for free API credits through a faculty/academic Catalyst Grant.

Eligibility
N/A — this is the absence of an offer. Verified across cohere.com (pricing, startup, research pages) and the Sep 2025 education blog post, which is Catalyst-Grants content only.
How to claim
Students: self-serve trial key for non-commercial use; apply (with a university/institution) to cohere.com/research/grants/application for public-benefit/open-science API credits.
Gotchas
Third-party perk aggregators (The Modelverse 'Cohere Free Trial API Key Free Student Deal', resets.pro, freellmapihub) list Cohere under student/research programs, but the 'student deal' entries are the generic trial key with fabricated framing (e.g. '365-day grant', '.edu verification') — Cohere requires no student verification. The only genuinely student-relevant first-party offer is the researcher-facing Catalyst Grant.
