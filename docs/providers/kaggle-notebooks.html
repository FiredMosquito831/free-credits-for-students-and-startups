Kaggle Notebooks: free credits and offers

Best offer on record: Kaggle Notebooks free GPU weekly quota (30 h/week, P100 or T4). 4 verified findings, checked 2026-10-22.

Offers

Kaggle Notebooks free GPU weekly quota (30 h/week, P100 or T4) high confidence

Official docs state Kaggle 'provides free access to NVIDIA TESLA P100 GPUs' and that the GPU quota 'resets weekly and is 30 hours or sometimes higher depending on demand and resources'. T4s (16 GB) were added as a GPU option alongside P100 in the 2023 notebooks update ('New GPU (T4s) options & more CPU RAM'). V100/A100 are not in the free pool. No credit card required; a free account suffices. Quota resets weekly (community tracking: Friday/Saturday midnight CET); the float above 30 h is not predictable. Interactive sessions have a 60-minute idle timeout (confirmed on the official GPU-usage tips page); batch (commit) sessions may run longer.

Eligibility
Any free Kaggle account (email/Google/Facebook sign-up). No .edu requirement, no CC. Phone verification (one-time SMS/voice call) gates accelerator access per secondary sources (medium confidence). Some regions have historically had restricted/intermittent accelerator availability (e.g., prior EU/UK data-sovereignty restrictions; exact 2026 state unverified — low confidence).
How to claim
Sign up at kaggle.com -> create/open a notebook -> Settings tab -> Accelerator dropdown -> select 'GPU' (or 'GPU T4') -> session runs against the 30 h/week pool; remaining hours shown in notebook sidebar / kaggle.com/notebooks / settings. No claim steps needed — quota is automatic on every account.
Expiry
Quota never expires; resets weekly (historically Sat 00:00 UTC / Fri midnight CET). Per-session: 60 min idle timeout for interactive sessions.
Gotchas
Quota counts session wall-time with accelerator attached, not actual GPU utilization — a T4 session parked open burns hours. Quota 'sometimes higher' is not in advance and can differ by region/demand. Phone verification required to enable accelerator. Free storage: ~20 GB notebook temp + 200 GB user datasets (secondary source, medium confidence).
Source
kaggle.com

Kaggle Notebooks free TPU weekly quota (~20 h/week, v2/v3 8-core) medium confidence

Kaggle offers free 8-core TPU access (TPU v2/v3 '8' nodes; v5e/v5lite available on request but intermittent). Widely documented quota is 20 TPU hours/week for TPUs, with a 9-hour max per session (task's known-so-far figure matches this). The TPU docs page at kaggle.com/docs/tpus 404'd during this check, so the 20 h figure is from pre-2026 documentation/secondary sources rather than a re-verified official page — treat as medium confidence and re-verify in-browser.

Eligibility
Any free Kaggle account; TPU access (especially v5e/v5lite) may need an email request to Kaggle support; availability is intermittent and region-dependent. No credit card.
How to claim
Notebook -> Settings -> Accelerator dropdown -> 'TPU v2/v3 8-core' (or request v5e/v5lite). 20 h/week pool shared across notebook sessions; check remaining hours in settings/usage panel.
Expiry
Resets weekly with GPU quota; 9 h max per TPU session.
Gotchas
Quota is shared per-week with no carryover; 9 h session cap is shorter than some GPU batch sessions; TPU pool availability fluctuates — your run can be queued or no-accelerator if pool is full; idle timeout still applies to interactive sessions.
Source
kaggle.com

Kaggle free CPU notebook time (~60 h/week) medium confidence

Notebooks also give a free weekly CPU allowance, commonly documented at 60 hours/week for 2-core / 13 GB RAM / 20 GB temp storage runs (secondary figure, not re-verified on an official page today — medium confidence). No CC required.

Eligibility
All free accounts; no phone verification typically needed for CPU-only sessions.
How to claim
Automatic on any account; select 'None' accelerator in notebook Settings.
Expiry
Resets weekly with the other pools.
Gotchas
CPU hours are tracked separately from GPU/TPU; 60 h figure has varied historically — verify in the in-app usage panel.
Source
kaggle.com

No separate Kaggle student or startup free-offer medium confidence

Kaggle does not run a distinct free student program, .edu-verified education license, or startup credit program for notebooks compute. Students and startups get the identical free Notebook quotas described above by virtue of a free account; Kaggle's education offering (courses, micro-credentials) is a separate thing and does not change compute quotas. If a startup-program search intended 'Kaggle startup credits', no such official program was found as of this check.

Eligibility
n/a — no distinct offer to claim.
How to claim
Nothing to claim; sign up free and use the general free quotas.
Expiry
n/a
Gotchas
Do not confuse Kaggle with GitHub Student Pack-style programs; Kaggle has no age/funding-cap or .edu-gating for compute access.
Source
kaggle.com
