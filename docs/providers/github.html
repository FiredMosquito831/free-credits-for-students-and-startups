GitHub Copilot Free (perpetual free tier, no credit card) high confidence

$0/month, no subscription or payment/credit card required. Includes up to 2,000 code completions/month, a (not numerically disclosed) allowance of GitHub AI Credits (1 AI credit = $0.01 USD), limited chat and agent usage via auto model selection only, Copilot CLI and the Copilot app. Under the legacy request-based system this was 50 premium requests/month; after the 2026-06-01 migration to AI-credit usage billing GitHub does not publish a fixed credit figure for the Free plan. Not available to users whose account is managed by an org/enterprise; personal use only. Never expires; limits reset monthly.

Eligibility
Any individual with a GitHub account not managed by an organization/enterprise and without an existing Copilot paid/Student/teacher/maintainer plan. No email domain, age, or region criteria stated. No credit card required. Region-limited only where Copilot is unavailable (standard Copilot availability restrictions apply).
How to claim
Sign up directly in VS Code/Visual Studio ('Sign up for Copilot Free'), via github.com/settings/copilot ('Start using Copilot Free'), or chat at github.com/copilot. No verification steps.
Expiry
Perpetual; monthly caps reset. Free/Student/teacher plans are reevaluated only where verification applies (Free has no verification, so no expiry).
Gotchas
Auto model selection only — no manual model picker, entry-level models only. Hitting the cap prompts an upgrade to Pro ($10). If you later join an org that assigns Copilot, Free access is lost. No code review, cloud agent, app modernization, or third-party agent delegation included. 'Unlimited completions' applies only to paid plans; Free caps at 2,000.
Source
github.com

GitHub Copilot Student (free education license for verified students) high confidence

Free for students verified through GitHub Education: unlimited code completions and next-edit suggestions (completions never consume credits), plus a monthly GitHub AI Credits allowance — community-reported at 200 credits/month (~$2.00 of agent/chat usage) since the 2026-06-01 credit-based billing; GitHub does not publish a single official dollar figure for students, so verify in your plan's usage display. Limited chat/agent usage, auto model selection only. Since 2026-03-12 students are on a dedicated 'Copilot Student plan' (UI shows it alongside GitHub Education benefits); premium models incl. GPT-5.4, Claude Opus and Sonnet are no longer self-selectable (GPT-5.3-Codex removed from the picker 2026-04-27); access to OpenAI/Anthropic/Google models continues via Auto routing. Eligibility is reevaluated monthly by GitHub.

Eligibility
Students aged 13+ enrolled in a degree- or diploma-granting course at an accredited institution. Verification is via school-issued email and/or official, dated proof of enrollment (no strict .edu requirement, but .edu helps). No credit card required. Global program (thousands of universities). Not available to managed org accounts.
How to claim
Apply at github.com/settings/education/benefits ('Start an application', complete verification — school email/proof). Once verified, under 'Free GitHub developer resources for students and teachers' click Learn more and activate Copilot Student (or github.com/github-copilot/free_signup). Activation can lag verification by a few days; do not complete a paid checkout while waiting.
Expiry
Persists while academic verification remains valid; GitHub reevaluates eligibility every month — access is withdrawn when no longer enrolled/verified. Model/limit adjustments are being rolled out in stages (GitHub said more model/limit changes would follow the 2026-03 transition).
Gotchas
Credit allowance (~200 credits / ~$2) is small: agent-mode sessions with newer models can exhaust it in one day (community reports of 4-20 agent requests using the full allocation post-June 2026). Auto model selection only, no manual picker. No third-party agents, code review, or cloud agent included. ~2M students use the program; GitHub is actively trimming it for sustainability.
Source
docs.github.com

GitHub Copilot Pro free for verified teachers and open-source maintainers (education/OSS license) high confidence

Full Copilot Pro at $0: unlimited completions, model selection, chat/agent/CLI, code review and cloud agent, and a $15/month AI-credit allowance (Base 1,000 + Flex 500 = 1,500 AI credits, 1 credit = $0.01). Two qualifying paths: (1) verified teacher on GitHub Education, (2) maintainer of a popular open-source repository (eligibility is determined by GitHub; objective repo thresholds are not publicly published — GitHub directs you to Copilot settings to see if you qualify).

Eligibility
Teachers: faculty at an accredited educational institution, verified via GitHub Education. OSS maintainers: maintainers of 'popular' open-source repos as judged by GitHub's criteria. Eligibility reevaluated monthly by GitHub.
How to claim
Teachers: apply/verify at github.com/settings/education/benefits, then activate in Copilot settings ('Get access to GitHub Copilot'). Maintainers: open Copilot settings; if eligible, a 'GitHub Copilot Pro' eligibility page appears — click Get access and save use policies. No payment info required for the free grant.
Expiry
While eligibility holds (monthly reevaluation). Note: if you are granted this free access you cannot cancel the plan — only losing eligibility ends it.
Gotchas
'Popular' OSS-maintainer criteria are opaque; if you don't see the offer you likely don't qualify. Free access is personal, not shareable to the team. If you later join an organization that assigns Copilot seats, the free grant may be displaced.
Source
docs.github.com
