  - *How to claim:* 1) Sign up for a free Adyen test account at ca-test.adyen.com (email + MFA). 2) In the test Customer Area, generate a test API key and a test Client API key for a test application (or use Adyen's pre-supplied test credentials). 3) Use Adyen's published test card numbers / test payment-method credentials to simulate transactions. 4) Build and test your integration against the test endpoint.
